# 刘羽的旅行 · 自驾点位图

从 B 站 UP 主「刘羽的旅行」(mid=523307153) 的 815 条自驾游视频中提取的
导航点位与路线的可交互地图。

- 桌面版: [pilot_map.html](https://vincenwx.github.io/liuyu-travel-map/pilot_map.html)
- 手机版: [pilot_map_mobile.html](https://vincenwx.github.io/liuyu-travel-map/pilot_map_mobile.html)（支持添加到主屏幕、离线使用）

## 数据说明

- 点位/路线来自视频标题、简介与 AI 字幕的规则解析 + 人工核对，坐标经地理编码与双重审计
- 路线几何来自 OSRM（OpenStreetMap 路网）
- 属性标签（免费/门票/人多预警等）为多条视频字幕的软证据聚合

## 使用边界

- 仅供个人旅行规划参考与非商业用途，请保留来源署名
- 点位精度：多数为村级/镇级（±1-2km），详情见点位弹窗坐标来源
- 数据版权归整理者所有，视频内容版权归原作者「刘羽的旅行」所有
